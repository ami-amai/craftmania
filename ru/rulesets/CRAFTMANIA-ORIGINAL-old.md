## Пространства

### Инвентарь

* Пространство для хранения предметов
* Имеется собственное у каждой команды
* Размер 3х3
* Начальная вместимость 3

### Игровое поле

* Игровое пространство, на котором происходят основные действия
* Владельцем пространства являются все играющие команды
* Размер 2х2 | 4x4 | 6x6 | 8x8
* Вместимость соотвествует размеру поля

## Действия

* Во время хода доступны различные действия

### Список действий

#### Перемещение

* Изменение положения предметов
    * Инвентарь <-> Игровое поле
    * По Игровому полю
    * По Инвентарю

#### Добыча

* Взятие предметов, если для этого соблюдены условия

#### Создание

* Добыча предметов, путем расходования рядом лежащих на поле, если для этого соблюдены условия
* По умолчанию, создание доступно только из одного предмета

#### Атака

* Опциональное перемещение оружия, результатом которого является разрушение предметов на поле
* После атаки ход автоматически переходит

## Здоровье и ХП

### Здоровье

* Запас ХП, которые игрок может получить за игру
* Как только Здоровье будет 

### ХП

* Шерсть, соответствующая цвету команды, которая используется для установки предметов на игровом поле
