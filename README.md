# КРАФТМАНИЯ

## Ядро

* Ядро для составления различных наборов правил. Содержит основные функции для реализации набора правил.

## Содержание ядра

* [**Набор правил**](#набор-правил)

### Объекты ядра

* [**Пространство**](#пространство)
* [**Предмет**](#предмет)
* [**Команда**](#команда)
* [**Ход**](#ход)
* [**Действия**](#действия)

## Набор правил

* Правила, основанные на ядре, и являющиеся отдельной игрой
* Может создавать различные объекты на основе ядра
* Может использовать различные логические конструкции для описания объектов и их свойств

## Объекты

## Пространство

* Место расположения предметов
* Владелецы могут взаимодействовать с полем

### Свойства пространства

* Размер
    * Длина
    * Ширина
* Владелец
    * [Команды](#команда)

## Предмет

* Вещь, с которой игрок может взаимодействовать

### Свойства предмета

* Идентификатор
* Статус
    * Прозрачный
    * Обычный
    * Особый
* Владелец
    * [Команды](#команда)
* Положение
    * [Пространство](#пространство)
    * Координаты пространства
        * Столбец
        * Строка

## Команда

* Группа игроков с равными правами

### Свойства команды

* Цвет
* Маркер
* Участники

## Ход

* Основная игровая стадия, в момент которой одна из [команд](#команда) выполняет [действия](#действия)

### Свойства хода

* Максимальное количество действий

## Действие

* Доступная активность во время [хода](#ход)
